Armazenamento

O painel mantém uma cópia local para contingência. Quando a Base Compartilhada estiver configurada e a liderança estiver autenticada, a base online se torna a fonte oficial e atualiza todos os dispositivos em tempo real.

Configuração da base compartilhada

Esta configuração é feita uma vez por dispositivo. Depois, a liderança usa apenas e-mail e senha. Quando a URL e a chave pública forem incorporadas ao app, esta etapa desaparece automaticamente.

Segurança: a chave anon pode ficar no navegador. O controle real de acesso é feito pelas regras RLS do banco. Não use a service_role key neste arquivo.

A nuvem passa a ser a base oficial após a conexão. Depois desta atualização histórica, um administrador/editor pode usar “Publicar base atualizada” para enviar também os registros consolidados de março a setembro.
